# 이현승 포트폴리오

**https://hyunsedu.github.io/portfolio/**

## 소개

로봇·AI 교육 콘텐츠를 만드는 사람입니다. 로봇공학을 전공하고 가르치는 일이 좋아 이 분야를 택했습니다. AI가 세상을 바꾸는 속도만큼 교육도 트렌드를 좇아 제작되어야 한다고 생각합니다. 새로 나온 기술을 먼저 익혀 아이들이 경험할 콘텐츠로 옮기는 일을 해 왔습니다.

2023년 11월부터 디지털새싹, 국립중앙과학관 과학캠프 같은 위탁 사업으로 콘텐츠 개발을 시작했습니다. 같은 교실에서도 학생마다 디지털·AI를 받아들이는 속도가 다르다는 것을 보고, 안산 강소특구 R&D 과제로 역량 진단 도구 DIMC를 설계해 제품에 적용했습니다. 이어서 도로랜드 캠프를 세계관부터 교구 도면, 웹 미션까지 개발했고, 온라인 학습 플랫폼 DOROBUS로 진단과 수업, 활동 기록을 한 계정에 묶었습니다.

커리큘럼 설계와 교재 집필, 교구 도면과 ESP32 제어 보드, 웹·앱 개발, 정부 과제 기획·수행, 캠프 운영과 강사교육까지 콘텐츠 하나가 수업이 되기까지의 전 과정을 맡아 왔습니다. 앞으로도 새로운 기술을 먼저 익혀 아이들이 변화를 마주할 힘을 키워 줄 콘텐츠를 만들어 나가려 합니다.
